The Problem

为什么需要焚诀？

当 AI Agent 的技能库膨胀到 150+ 且分散在 5 个平台时，管理变成了一场噩梦。

🔀

技能孤岛

5 个 AI 平台（OpenClaw / WorkBuddy / Claude Code / TRAE / QoderWork）各自维护独立技能库。在一个平台安装的技能，其他平台完全不知道。重复安装、版本漂移、手动同步成为日常。

5 平台 × 150+ skill = 手动同步地狱
🧠

记忆断裂

每个 Agent 有独立记忆系统，跨会话经验无法沉淀。同一个错误在不同平台反复犯，踩坑教训无法共享，每次对话都从零开始。

经验留存率 ≈ 0%（跨平台）
🎯

路由失明

150+ 技能摆在面前，但 Agent 不知道该用哪个。纯关键词匹配的初始命中率只有 6.7%——相当于 100 次调用里只有 7 次找对了工具。

初始 Top-1 命中率: 6.7%
Solution

三大主线，平行推进

从 2026 年 7 月 4 日的一个朴素需求，演化为三线并行的完整系统。

01

跨平台技能互通

通过 Junction 符号链接 + 自动同步脚本，实现任一端增删技能后全端自动感知。157 项技能目录 diff=0，完全闭环。

Junction 同步 Registry V2.0 190 条注册 周自动同步
02

统一记忆 + 路由

<memory-root> 作为多端共享的统一记忆权威源，配合 skill_routing（13 领域）+ intent_classifier（116 条精确路由），让每个 Agent 都拥有完整上下文。

global_memory 13 领域路由 三级意图分类 经验自动沉淀
03

命中率优化

四层管线架构：直连映射（43 条正则短路）→ Tag 倒排索引（465 标签）→ BGE 语义向量 → Memory 上下文增强。从 6.7% 一路飙升到 93.4%。

DIRECT_MAP Tag 系统 BGE 语义 LLM 消歧
