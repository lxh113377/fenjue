# 图表渲染（Agent Skills 标准目录格式示例）

本目录形态 = `<skill-name>/SKILL.md`，即 anthropics/skills 用的规范布局。
本仓的 `eval/hitrate_cli.py` 直接吃这种目录，无需先翻译成扁平 `*.md`。

## 何时使用

用户给一份数据文件并问「画个图」「可视化一下」，或需要指定图型与坐标轴时。
